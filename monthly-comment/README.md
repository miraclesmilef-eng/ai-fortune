# 月次コメント自動生成ツール

試算表のCSVから、顧問先へそのまま送れる月次報告コメントを生成します。
`index.html` を開くだけで動きます（サーバー・APIキー・通信は不要。データはブラウザ内で処理され、外部に送信されません）。

## 使い方

1. `index.html` をブラウザで開く
2. 「サンプルを読み込む」を押す（自分のデータを使う場合はCSVを貼り付けるかファイルを選択）
3. 顧問先名・事務所名・対象月・文体を設定して「コメントを生成する」

## CSVの形式

| 列 | 内容 | 必須 |
|---|---|---|
| 1列目 | 勘定科目 | 必須 |
| 2列目 | 当月 | 必須 |
| 3列目 | 前月 | 任意（あると前月比の分析が出ます） |
| 4列目 | 前年同月 | 任意（あると前年同月比の分析が出ます） |

- 1行目はヘッダーとして扱われます（2列目が数値ならデータ行として読みます）
- カンマ区切りの金額、全角数字、`▲` `△` `( )` 付きの負数に対応
- 「売上高」の行は必須。それ以外は揃っている分だけ分析されます

サンプル: [`sample.csv`](./sample.csv)

## 生成される内容

- **今月の業績** — 売上高、売上総利益率、営業利益（前月比・前年同月比つき）
- **good** — 増収、粗利率の改善、借入金の減少など
- **注意して見ておきたい点** — 粗利率の低下、販管費の増加、前月比で大きく動いた経費科目、売掛金の滞留兆候、現預金の月商倍率割れ、赤字転落
- **資金の状況** — 現預金残高と月商倍率、借入金残高
- **来月に向けて** — 検出した論点に応じたアクション提案

文体は「ていねい（送付メール向け）」と「簡潔（面談メモ向け）」を切り替えられます。

## 判定のしきい値

| 項目 | 条件 |
|---|---|
| 粗利率の改善／低下 | 前月比 ±0.5ポイント以上 |
| 販管費の増加 | 前月比 +3%以上 |
| 大きく動いた経費科目 | 増減額10万円以上、または増減率30%以上かつ増減額3万円以上（上位3件） |
| 売掛金の滞留兆候 | 売掛金の前月比が売上の前月比を10ポイント以上上回る |
| 現預金の注意 | 月商1か月分を下回る |

実務に合わせて `index.html` 内の `generate()` と `analyze()` の数値を調整してください。

## 位置づけ

Addness の Claude Code 導入支援における、士業・中小企業向けのデモ用サンプルです。
「非エンジニアが、実務で使える業務ツールを短時間で内製できる」ことを示すための成果物で、
生成されるコメントはあくまで下書きです。顧問先への送付前には必ず内容をご確認ください。
